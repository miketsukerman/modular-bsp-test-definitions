# usb (`adv-usb`)

USB checks: host-bus enumeration with `lsusb`, optional plugged-device
port/driver/speed matching, and optional USB OTG kernel-configuration checks
plus an Ethernet-gadget functional skip stub.

* **Definition:** [`automated/linux/usb/usb.yaml`](../../automated/linux/usb/usb.yaml)
* **Script:** [`automated/linux/usb/usb.sh`](../../automated/linux/usb/usb.sh)

## Scope

**Covered**

* `lsusb` lists at least one USB device on the host bus.
* Specific plugged USB devices match configured `lsusb -t` port, driver, and
  speed values.
* When OTG is enabled, configured kernel config keys are present as `=y` or `=m`
  in `/proc/config.gz` or `/boot/config-$(uname -r)`.
* `L-USB-OTG-ETH-F` is emitted as a skip stub when `CONFIG_USB_ETH` is included
  in `USB_OTG_CONF`.

**Not covered**

* USB storage throughput, HID operation, device reset behaviour, suspend/resume,
  or OTG cable negotiation.
* Functional OTG Ethernet traffic; the script only emits a skip stub for that
  case.

## Prerequisites

* **Hardware:** specific USB devices must be plugged into the configured ports
  for `USB_DEV_COUNT` entries; OTG Ethernet would require suitable USB cabling
  but is currently a skip stub.
* **Target tools:** `lsusb` for host and plugged-device checks; `zcat`, `grep`,
  and `uname` for OTG kernel-config checks.
* **Root:** not normally required; kernel config files must be readable for OTG
  checks.

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `USB_DEV_COUNT` | `"0"` | Number of specific plugged USB devices to iterate over (`dev0` … `dev<COUNT-1>`); `0` means no plugged-device checks |
| `USB_DEV{N}_PORT` | `""` | USB port number as shown by `lsusb -t`; empty skips that plugged-device check |
| `USB_DEV{N}_DRIVER` | `""` | Expected driver name in `lsusb -t`; empty skips that plugged-device check |
| `USB_DEV{N}_SPEED` | `""` | Expected speed in `lsusb -t`, for example `480M`; empty skips that plugged-device check |
| `USB_OTG_ENABLED` | `"0"` | `1` or `y` = run OTG kernel-config checks |
| `USB_OTG_CONF` | `""` | Space-separated kernel config keys to verify when OTG is enabled |
| `VERBOSE` | `"0"` | `"1"` enables per-test-case diagnostic logs |

The host-bus check always runs. Plugged-device and OTG checks are controlled by
their count and enable parameters.

## Test cases

IDs are shown in sanitised (LAVA) form. `${cfg_key}` is the literal kernel
config key from `USB_OTG_CONF`.

| Test case ID | Functional | Pass | Fail | Skip / not emitted |
|--------------|:----------:|------|------|--------------------|
| `L-USB-HOST-DEV` | | `lsusb` exists and reports at least one line | `lsusb` exists but reports zero devices | `skip` when `lsusb` is missing |
| `L-USB-PLUGGED-DEV-F-dev{N}` | ✓ | `lsusb -t` has a non-root, non-hub interface on the configured port with matching driver and speed | No matching `lsusb -t` entry found | `skip` when port, driver, speed, or `lsusb` is missing; not emitted when `USB_DEV_COUNT=0` |
| `L-USB-OTG-CONF-${cfg_key}` | | Config key is present as `=y` or `=m` in the readable kernel config | Config key is absent or kernel config cannot be read | Not emitted unless OTG is enabled and `USB_OTG_CONF` contains the key |
| `L-USB-OTG-ETH-F` | ✓ | Not emitted as `pass` by the script | Not emitted as `fail` by the script | `skip` when OTG is enabled and `USB_OTG_CONF` contains `CONFIG_USB_ETH`; otherwise not emitted |

## Running locally

```sh
cd automated/linux/usb
USB_DEV_COUNT=1 \
USB_DEV0_PORT=1 \
USB_DEV0_DRIVER=usb-storage \
USB_DEV0_SPEED=480M \
USB_OTG_ENABLED=1 \
USB_OTG_CONF="CONFIG_USB_GADGET CONFIG_USB_ETH" \
bash usb.sh
cat output/result.txt
```

## Verbose logging

With `VERBOSE=1` the script writes `output/<test-case-id>.log` for
`L-USB-HOST-DEV`, `L-USB-PLUGGED-DEV-F-*`, and `L-USB-OTG-CONF-*` checks. Host
and plugged-device logs include raw `lsusb`/`lsusb -t` output where requested;
OTG logs include the config key and found state. LAVA surfaces these logs
alongside the test result.

## Troubleshooting

| Symptom | Likely cause |
|---------|--------------|
| `L-USB-HOST-DEV` skips | `lsusb` is not installed on the target image |
| `L-USB-HOST-DEV` fails | No USB devices are enumerated, or host-controller support is missing |
| `L-USB-PLUGGED-DEV-F-*` skips | Port, driver, or speed parameter is empty, or `lsusb` is missing |
| `L-USB-PLUGGED-DEV-F-*` fails | Device is not plugged into the expected port, driver name differs, or negotiated speed differs |
| `L-USB-OTG-CONF-*` fails | Kernel config is unavailable or the requested config key is not enabled as built-in/module |
| `L-USB-OTG-ETH-F` skips | Expected behaviour; OTG Ethernet traffic is a skip stub in the script |
