# context (`adv-context`)

Context checks: operating-system identity, operating-system version, minimum
kernel version, CPU model string, and BIOS release date. Empty expected values
remove the corresponding test case from the results.

* **Definition:** [`automated/linux/context/context.yaml`](../../automated/linux/context/context.yaml)
* **Script:** [`automated/linux/context/context.sh`](../../automated/linux/context/context.sh)

## Scope

**Covered**

* Distro ID and version are read from `/etc/os-release` through shared helpers.
* Kernel major/minor version from `uname -r` is compared with a configured
  minimum.
* CPU model is collected from `/proc/cpuinfo`, `lscpu`, device tree, or
  `uname -m` and matched as a case-insensitive substring.
* BIOS date is read from sysfs or `dmidecode` and compared after normalising
  `MM/DD/YYYY` to `YYYYMMDD`.

**Not covered**

* Package set, image provenance, bootloader version, or kernel configuration.
* BIOS minimum-date ordering; the script checks exact equality after
  normalisation despite the test-case name.
* CPU feature flags or topology.

## Prerequisites

* **Hardware:** none beyond normal platform firmware and CPU identity sources.
* **Target tools:** `uname`, `grep`, `awk`, `cat`, and `xargs`; `lscpu` and
  `dmidecode` are optional fallbacks for CPU model and BIOS date.
* **Root:** not required by the script, although some targets may restrict the
  optional `dmidecode` fallback.

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `DISTRO_ID` | `"yocto"` | Expected distro ID as a case-insensitive substring; empty = check not emitted |
| `DISTRO_VER` | `""` | Expected distro version as a case-insensitive substring; empty = check not emitted |
| `KERNEL_MIN_VER` | `"6.6"` | Minimum kernel major/minor version, for example `6.6`; empty = check not emitted |
| `CPU_MODEL` | `""` | Expected CPU model substring; empty = check not emitted |
| `BIOS_DATE` | `""` | Expected BIOS date in `YYYYMMDD` form after normalisation; empty = check not emitted |
| `VERBOSE` | `"0"` | `"1"` enables per-test-case diagnostic logs |

## Test cases

IDs are shown in sanitised (LAVA) form.

| Test case ID | Functional | Pass | Fail | Skip / not emitted |
|--------------|:----------:|------|------|--------------------|
| `L-SW-DISTRO-ID` | | Helper-reported distro ID contains `DISTRO_ID` case-insensitively | Distro ID does not contain the expected substring | Not emitted when `DISTRO_ID` is empty |
| `L-SW-DISTRO-VER` | | Helper-reported distro version contains `DISTRO_VER` case-insensitively | Distro version does not contain the expected substring | Not emitted when `DISTRO_VER` is empty |
| `L-SW-KERNEL-MIN-VER` | | Running kernel major/minor is greater than or equal to `KERNEL_MIN_VER` | Running kernel is older than the configured minimum | Not emitted when `KERNEL_MIN_VER` is empty |
| `L-CPU-MODEL` | | Detected CPU model contains `CPU_MODEL` case-insensitively | CPU model is missing or does not contain the expected substring | Not emitted when `CPU_MODEL` is empty |
| `L-BIOS-DATE-MINIMUM` | | Normalised BIOS date exactly equals `BIOS_DATE` | BIOS date is missing or differs | Not emitted when `BIOS_DATE` is empty |

The distro helper reports `yocto` for OpenEmbedded/Poky-style images even when
`/etc/os-release` uses a more specific ID.

## Running locally

```sh
cd automated/linux/context
DISTRO_ID=yocto \
DISTRO_VER="" \
KERNEL_MIN_VER=6.6 \
CPU_MODEL="Cortex-A35" \
BIOS_DATE="" \
bash context.sh
cat output/result.txt
```

## Verbose logging

With `VERBOSE=1` the script writes `output/<test-case-id>.log` for emitted
checks, recording the expected value and the value read from the target. LAVA
surfaces these logs alongside the test result.

## Troubleshooting

| Symptom | Likely cause |
|---------|--------------|
| `L-SW-DISTRO-ID` fails | Expected ID does not match `/etc/os-release`, or the image is not detected as Yocto/OpenEmbedded |
| `L-SW-KERNEL-MIN-VER` fails | Kernel major/minor version is older than the configured minimum |
| `L-CPU-MODEL` fails | Expected model substring is too specific for the target's `/proc/cpuinfo`, `lscpu`, or device-tree model |
| `L-BIOS-DATE-MINIMUM` fails | Firmware date differs, sysfs DMI data is unavailable, or the expected date is not in `YYYYMMDD` form |
