# ram (`adv-ram`)

RAM checks: configured memory size and optional speed, minimum total RAM, a
reported total-RAM measurement, and a bounded `memtester` stability run.

* **Definition:** [`automated/linux/ram/ram.yaml`](../../automated/linux/ram/ram.yaml)
* **Script:** [`automated/linux/ram/ram.sh`](../../automated/linux/ram/ram.sh)

## Scope

**Covered**

* For each configured slot, expected RAM size compared with `physical_ram_MB`.
* Optional configured RAM speed compared with `physical_ram_MT`.
* `/proc/meminfo` `MemTotal` is at least `RAM_MIN_AVAIL`, and the total is
  emitted as a measurement in MiB.
* A bounded `memtester <size>M 1` run, using a percentage of `MemAvailable`, an
  upper MiB cap, and an optional `timeout` wrapper.

**Not covered**

* True per-DIMM slot attribution; the script compares each configured slot size
  with the total physical RAM value returned by the helper.
* Long-duration burn-in, ECC error counters, memory bandwidth, or thermal stress.

## Prerequisites

* **Hardware:** RAM installed according to the board configuration.
* **Target tools:** `dmidecode` for DMI-based size/speed readings (the size
  helper falls back to `/proc/iomem`); `memtester` for the stability case;
  `timeout` is optional and bounds the `memtester` run when present.
* **Root:** recommended. `dmidecode` usually requires root, and large memory
  allocations are more predictable in a controlled root LAVA job.

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `RAM_SLOT_COUNT` | `"1"` | Number of RAM slot entries to iterate over (`slot0` … `slot<COUNT-1>`) |
| `RAM_SLOT{N}_SIZE` | `"1024"` | Expected size for slot `N` in MB/MiB; `0` or non-numeric = size check not emitted |
| `RAM_SLOT{N}_SPEED` | `""` | Expected speed for slot `N` in MT/s; empty = speed check not emitted |
| `RAM_MIN_AVAIL` | `"800"` | Minimum `/proc/meminfo` `MemTotal` in MiB; `0` or non-numeric = minimum and total-metric checks not emitted |
| `RAM_STABILITY_FRACTION` | `"50"` | Percentage of `/proc/meminfo` `MemAvailable` to request for `memtester` |
| `RAM_STABILITY_MAX_MB` | `"256"` | Hard upper bound for the `memtester` allocation in MiB |
| `RAM_STABILITY_TIMEOUT` | `"300"` | Maximum seconds for `memtester` when `timeout` is installed |
| `VERBOSE` | `"0"` | `"1"` enables per-test-case diagnostic logs |

The stability size is `MemAvailable * RAM_STABILITY_FRACTION / 100`, converted
to MiB and capped by `RAM_STABILITY_MAX_MB`.

## Test cases

IDs are shown in sanitised (LAVA) form. `${label}` is `slot<N>` for slot `N`.

| Test case ID | Functional | Pass | Fail | Skip / not emitted |
|--------------|:----------:|------|------|--------------------|
| `L-RAM-SIZE-${label}` | | `physical_ram_MB` equals `RAM_SLOT{N}_SIZE` | Size differs or no physical size could be read | Not emitted when `RAM_SLOT{N}_SIZE` is `0` or not numeric |
| `L-RAM-SPEED-${label}` | | `physical_ram_MT` equals `RAM_SLOT{N}_SPEED` | Speed differs or cannot be read | Not emitted when `RAM_SLOT{N}_SPEED` is empty |
| `L-RAM-AVAILABLE-MIN` | | `MemTotal` is greater than or equal to `RAM_MIN_AVAIL` | `MemTotal` is below `RAM_MIN_AVAIL` | Not emitted when `RAM_MIN_AVAIL` is `0` or not numeric |
| `L-RAM-AVAILABLE-TOTAL` | | Always emitted as `pass` with the measured `MemTotal` in `MiB` | — | Not emitted when `RAM_MIN_AVAIL` is `0` or not numeric |
| `L-RAM-STABILITY-F` | ✓ | `memtester <mib>M 1` exits with status `0` | `memtester` exits non-zero or `timeout` returns `124` | `skip` when computed test size is `0` MiB or `memtester` is not installed |

## Running locally

```sh
cd automated/linux/ram
RAM_SLOT_COUNT=1 \
RAM_SLOT0_SIZE=1024 \
RAM_SLOT0_SPEED=3200 \
RAM_MIN_AVAIL=800 \
RAM_STABILITY_FRACTION=50 \
RAM_STABILITY_MAX_MB=256 \
RAM_STABILITY_TIMEOUT=300 \
bash ram.sh
cat output/result.txt
```

## Verbose logging

With `VERBOSE=1` the script writes `output/<test-case-id>.log` for emitted
size, speed, minimum-RAM, total-RAM metric, and stability checks, each ending in
a `RESULT:` line. The `memtester` command still streams to the console even
without verbose logging so LAVA does not time out on silence.

## Troubleshooting

| Symptom | Likely cause |
|---------|--------------|
| `L-RAM-SIZE-*` fails | Expected size does not match the total size reported by `dmidecode` or `/proc/iomem` |
| `L-RAM-SPEED-*` fails | `dmidecode -t memory` does not report the expected configured MT/s value |
| `L-RAM-AVAILABLE-MIN` fails | Kernel-reserved memory leaves `MemTotal` below `RAM_MIN_AVAIL`, or the threshold is too high |
| `L-RAM-STABILITY-F` is skipped | `memtester` is missing, or the computed test allocation is `0` MiB |
| `L-RAM-STABILITY-F` fails with timeout | Increase `RAM_STABILITY_TIMEOUT`, reduce `RAM_STABILITY_FRACTION`, or reduce `RAM_STABILITY_MAX_MB` |
